# Graphel

Sitio de una agencia de diseño multimedia con cuatro páginas enlazadas: inicio, nosotros, servicios y contacto, y un formulario de suscripción. Construida desde cero con HTML y CSS a partir de un diseño, como práctica de maquetación web.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)

**[Ver demo en vivo](https://rich4rdx.github.io/proyecto-graphel/)**

![Vista previa de Graphel](docs/preview.jpg)

## Qué practiqué

- Maquetación semántica con HTML5 (`header`, `nav`, `section`, `footer`)
- Distribución de secciones con Flexbox
- Varias páginas enlazadas con navegación compartida

## Cómo verlo en tu computador

```bash
git clone https://github.com/Rich4rdx/proyecto-graphel.git
```

Abre `index.html` en el navegador. No necesita instalar nada.
